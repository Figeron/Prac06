Windows объединяет всё в WMI, потому что так проще централизованно управлять системой:
Единая точка доступа - один интерфейс для железа, ОС, служб и настроек, не нужно держать кучу разных API.
Унифицированная модель данных - всё описано в виде классов и свойств, запросы строятся по одному шаблону (WQL).
Связь объектов - можно сразу соотнести диск с разделами, службой или драйвером, а не собирать данные по частям.
Автоматизация и мониторинг - удобно делать инвентаризацию, подписки на события и удалённое управление через один механизм.
